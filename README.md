# Sovereign Market Terminal — Zero-Dependency Financial Tools for Windows

**Built for Non-Coders • Zero Python • Zero API Keys • Zero Subscriptions • MADE IN YORKSHIRE**

Two lightweight, double-clickable Windows utilities that give you instant access to live stock market charts, fundamentals, and raw market data—without browser bloat, paywalls, or tracking scripts.

---

## 📦 What’s Included (Just Download & Double-Click)

| Tool | What It Does | Output |
| :--- | :--- | :--- |
| **`fin-search.exe`** | **Visual Chart & Quote Terminal:** Enter any stock tickers (`NVDA, ANT, ASML, AMD, TSLA`) to build an instant dark-mode dashboard with one-click links to Finviz charts, fundamentals, and insider filings. | Self-contained `.html` board (auto-opens in your browser) |
| **`fin-data.exe`** | **Live Equity Data Harvester:** Authenticates directly with Yahoo Finance to pull live prices, `$` and `%` daily changes, intraday high/low ranges, and trading volume. | Console readout + timestamped `.csv` spreadsheet + phosphor-green `.html` dashboard |

---

## 🚀 How to Use (For Non-Coders)

1. **Download** `fin-search.exe` and `fin-data.exe` from the **Releases** page (or directly from this repository) into any folder on your Windows PC.
2. **Double-click** either `.exe` file to launch it.
   * *Note: Because these are independent, unsigned community tools, Windows SmartScreen may show a blue **"Windows protected your PC"** popup the first time you run them. Click **More info** -> **Run anyway**.*
3. **Type your stock tickers** separated by commas (for example: `NVDA, ANT, TSLA`) or press **Enter** to run the default watchlist.
4. Your permanent **`.html`** dashboard (and **`.csv`** spreadsheet from `fin-data.exe`) will be saved right into the same folder and open automatically in your web browser.
